She checks.
You decide.

  1. Ask

    In your app's folder, tell Claude in your own words: “Sofia, check my app.”

  2. Check

    She opens the app in your own Chrome, clicks the buttons, fills the forms and reads the code. What doesn't apply is skipped, with the reason.

  3. Talk it through

    A score, the blockers by name, the rest by urgency. Ask why, push back, mute something. She offers one compromise and respects a no.

  4. Fix what you approved

    A checkpoint, the fix, then the check runs again. Only a passing re-check counts as fixed. Every fix can be undone on its own.

Nothing changes
without a yes.

  • No fix without a yes

    She shows, explains and recommends. She changes only what you approved, when you say go.

  • Fixed means re-checked

    Fixed only after its check runs again and passes, not because the code changed.

  • A real second opinion

    Judgment calls go to a separate reviewer that hasn't seen your chat and must quote the exact line.

  • No surprises

    No real form submissions, email or purchases without asking first.

  • Same app, same report

    Every check that can be a script is a script, so results don't drift between runs.

  • Stays on your computer

    Your code and results go nowhere. No accounts, no paid services.

Add Sofia to Claude Code

/plugin marketplace add avivalushai/sofia

Install her

/plugin install sofia@sofia

Then say “Sofia, check my app” or type /sofia:check. For a check that takes seconds, /sofia:check quick.

You need Claude Code, Google Chrome and Node.js 20 or newer.

# Rubric: content.404-copy — Not-found page copy

Everyone hits a not-found page sometimes: an old link, a typo, a moved page. A good one keeps them on the site. A bare "404" makes them leave.

Read the not-found page you were given.

1. **Does it say in plain words that the page wasn't found?**
   Fail: only "404", "Not Found", or a technical message.
   Pass: "We can't find that page", "הדף שחיפשתם לא נמצא".
2. **Does it offer a way forward?**
   Fail: no link at all, or only the browser's back button.
   Pass: a link to the home page, plus at best the main sections, a search box, or a contact link.
3. **Does it look like part of the site (the same header or navigation, the same style)?**
   Fail: a plain page with none of the site's header, logo or styles.
   Pass: it uses the site's layout or at least its logo and colours.

Findings: one finding for the page, quoting the line closest to the problem. Options: (1) a friendly message with links to the home page and the main sections (recommended); (2) add a search box as well; (3) keep it as it is.

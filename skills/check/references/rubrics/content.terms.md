# Rubric: content.terms — Inconsistent wording

The same action or thing called by different names across screens ("Sign up" here, "Register" there, "Join" on a third) makes people wonder whether these are different things.

Read `pages.txt` (the visible text of each page) and any other files you were given. Answer each question.

1. **Is the same action named differently in different places?**
   Fail: "Sign up" / "Register" / "Create account" for the same flow; "הרשמה" / "הצטרפות" / "פתיחת חשבון".
   Pass: one name everywhere (a button "Sign up" and a heading "Create your account" on the same page is fine — that's a description, not a rename).
2. **Is the same thing (an object in the app) named differently?**
   Fail: "Projects" in the menu, "Workspaces" in settings, "Boards" on the dashboard — for the same thing.
   Pass: consistent names.
3. **Is the tone or form of address mixed in a way visitors will notice?**
   Fail: Hebrew text that switches between masculine, feminine and plural address on the same screen ("הירשם" next to "הירשמי"); English mixing "you" with "the user".
   Pass: one form throughout, or a deliberate neutral form.

Only flag real inconsistencies a visitor would notice. Slang, brand words and the owner's own style are not problems — when you can't tell whether something is deliberate, answer uncertain.

Findings — one per group of names for the same thing, quoting where each appears. This check is `choice`: options are the candidate names, most-used first ("Use 'Sign up' everywhere (used 5 times)").

# Rubric: privacy.licenses — Font and image licenses

Fonts and images copied from the web often come with licences that don't allow use on a commercial site. Font foundries and stock photo agencies (Getty Images, for example) send invoices and legal letters, sometimes years later.

You were given the stylesheets and font files the site uses, the image files it ships, and any credit or licence notes in the project.

1. **Are all fonts free for commercial web use, or clearly licensed?**
   Fail: font files of commercial typefaces served from the site's own files (for example Helvetica Neue, Futura, Gotham, Proxima Nova, Avenir, or commercial Hebrew fonts like Narkis, FbAsimon, Ploni, Almoni) with no licence file or note.
   Pass: Google Fonts or other open-licence fonts (OFL), system fonts, a font service with an account (Adobe Fonts, Fontshare), or a licence file in the project.
2. **Do the images look like stock or other people's work used without a licence?**
   Fail: file names or contents that point to stock agencies (`shutterstock_123`, `GettyImages-`, `iStock-`, `depositphotos_`, `AdobeStock_`, watermarked previews) with no licence note; images saved from other sites (a news site's or another company's file names).
   Pass: the business's own photos, free licences (Unsplash, Pexels) or a licence note.
3. **Where a licence requires credit, is it given?**
   Fail: Creative Commons BY images or icons, or free icon sets that require attribution (Flaticon free, Freepik), with no credit anywhere.
   Pass: credit given, or the source doesn't require it.

Findings: one for each file or group of files, with the file path as the quote. Options: (1) replace it with a free alternative, and I'll suggest one (recommended); (2) buy the licence; (3) keep it (you already have a licence).
